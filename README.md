# excel-basico
Exercícios práticos de Excel — nível básico
Este repositório reúne meus estudos e exercícios práticos de Microsoft Excel, com foco no desenvolvimento de conhecimentos básicos e aplicação de fórmulas e funções.

Conteúdos estudados:
- Cálculos matemáticos
- SOMASE
- MÁXIMO, MÍNIMO e MÉDIA
- Porcentagem
- Referências relativas e absolutas
- Data e hora
- AGORA e HORA
- Localizar e substituir
- MAIÚSCULA e MINÚSCULA
- CONCATENAR

Objetivo:
Registrar minha evolução no aprendizado de Excel por meio de exercícios práticos e exemplos.

Ferramentas utilizadas:
- Microsoft Excel
- GitHub
